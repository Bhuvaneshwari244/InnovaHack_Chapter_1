#### Backend (Render.com)
1. Go to https://render.com
2. Sign up (free)
3. Click "New +" → "Web Service"
4. Connect your GitHub (or upload files)
5. Settings:
   - Name: `smart-expense-api`
   - Root Directory: `backend`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `gunicorn app:app`
6. Click "Create Web Service"
7. **Copy the URL**: `https://smart-expense-api.onrender.com`

#### Frontend (Vercel.com)
1. Go to https://vercel.com
2. Sign up (free)
3. Click "Add New" → "Project"
4. Import from GitHub (or upload files)
5. Settings:
   - Name: `smart-expense-app`
   - Root Directory: `frontend`
   - Framework Preset: Vite
6. Environment Variables:
   - Key: `VITE_API_URL`
   - Value: `https://smart-expense-api.onrender.com/api`
7. Click "Deploy"
8. **Copy the URL**: `https://smart-expense-app.vercel.app`
